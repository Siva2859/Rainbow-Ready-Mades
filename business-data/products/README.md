# Products Intake Instructions

Store real garment records here. For each real product identified at Rainbow Ready Mades:
1. Duplicate `product_template.json` and name it using the product ID, for example: `prod_001.json`.
2. Fill out all verified details accurately.
3. Save corresponding authentic photographs taken at the shop inside `assets/products/` using matching IDs (e.g. `assets/products/prod_001_main.jpg`).
4. Never invent products or guess prices.
